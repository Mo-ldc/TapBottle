## 实现要点（Core/Wm.ts）

- 触发层 = **全局输入轮询**（`input.on(TOUCH_START/MOVE/END/CANCEL)` + 40ms 兜底 ticker），
  不挂节点事件 → 不受 ScrollView / BlockInputEvents / `pressable` 影响。
- 坐标口径：`e.getUILocation() + view.getVisibleOrigin()`（世界）vs
  `UITransform.getBoundingBoxToWorld()` —— 两者同为世界坐标，可直接比。
- `nodeRect()` 带 `isValid && activeInHierarchy` 判定 → 弹窗关闭后节点失效，矩形自动为 null，
  **无需手动注销**，重复 open 也只是多注册几份（都指向失效节点）。
- 筹码两处用 `Wm.tapsRect(() => Tutorial.active ? null : Wm.nodeWorldRect(node), ...)` 门控：
  引导幕布四块挂了 BlockInputEvents 会挡住筹码 → **引导期间必须停用**，否则玩家一进来就在引导里，
  触发点等于不存在（且引导洞里自动翻瓶会干扰）。
