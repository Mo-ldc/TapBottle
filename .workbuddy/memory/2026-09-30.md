# 第123轮：水印触发点返工（用户实测 5 个问题）

## 用户反馈 → 根因 → 修法
1. **开始页没有 logo** / **开始界面没有副标题** → `StartPage.prefab` 里**根本没有**
   `logo`/`subTxt`/`tapTxt` 节点（`@property` 全是 `None`）：节点在历次改版中被删了，
   代码里的绑定一直是空引用。→ 新增 `Wm.ensureStartNodes()` 运行时建 `wmLogo`/`wmSub`
   两个透明占位节点（560×560 / 420×60），不依赖 prefab。
2. **别把触发放在新手引导** → 引导幕布四块 `mT/mB/mL/mR` 都挂了 `BlockInputEvents`，
   顶栏筹码在引导期间被幕布盖住（新玩家一进游戏就是引导 → 触发点等于不存在）。
   → `Hud` 的筹码触发加 `Tutorial.active ? null : rect` 门控（引导期间停用）。
3. **成就页第一栏没法触发** / **长按都触发不了** → 两个原因叠加：
   ① 行卡片在 `ScrollView` 里，**ScrollView 吞触摸**转成滚动，节点收不到稳定
      TOUCH_START→TOUCH_END 配对；② 长按原用节点 `TOUCH_START` + `setTimeout`。
   → 全部改**全局输入轮询**（`Wm.holdNode/taps` 挂 `input.on(TOUCH_*)`，
   每帧比对世界矩形 + 停留时长），彻底绕开 ScrollView / BlockInputEvents。
   → 成就/统计的长按目标从「滚动区第一行」挪到 `frame` 上的**底部铭牌**
   （`Wm.ensurePanelPlate`，y=-478，不在滚动区 → 不随内容滚走、不被吞事件）。
4. **长按方式貌似都无法触发** → 同 3。

## 坐标口径（本轮最大坑）
- 判定必须统一到**世界坐标**：`getUILocation() + view.getVisibleOrigin()` → 世界坐标
  （项目既有入口 `BottleField.uiToWorld`；`getUILocation` 是视口坐标，与世界坐标差
  `visibleOrigin`，屏幕比例偏离 9:16 就整片错位）。
- 节点侧用 `UITransform.getBoundingBoxToWorld()`（同为世界坐标，含父链缩放）→ 两者可直接比。
- ⚠️ 曾误用 `input.EventType`（应为 `Input.EventType`，实例上没有 EventType）。

## 验收工具增强（E:/LDC_Fby/_cdp.py）
- 新增 `jshold:<JS 返回[x,y]>|<按住ms>`（长按）、`jstaps:<JS>|<次数>|<间隔ms>`（连点）、
  `jstouch:<JS>|<次数>|<间隔ms>|<按住ms>`（真实 touch 事件，Input.dispatchTouchEvent）。
- ⚠️ **headless 下 `Input.dispatchMouseEvent` / `dispatchTouchEvent` 注入的点击事件
  页面收不到**（原生 mousedown/touchstart 监听实测 0 条；jsdrag 预热也只能收到 1 条）。
  结论：**点击/长按类交互本轮无法自动验收**，只能验几何 + 用 `__wm.*` 钩子验展示链路。
  实机或带 UI 的浏览器需人工确认。
